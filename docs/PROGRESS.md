## Связь с автошколой
Тестовый стек Driving School — источник изученных конфигурационных решений, но его локальный успех не означает завершения Supabase Lite. Продукт Lite не должен содержать schema-only dump, приватные данные, триггер профилей или бизнес-логику Driving School.

## Риски
1. Ограничения памяти VDS при одновременном запуске двух стеков — перед экспериментами необходим capacity preflight.
2. Docker networking и маршрутизация localhost/API gateway — отдельно тестировать.
3. Миграции системных ролей, Storage и версии компонентов — не считать совместимыми без тестов.
4. Искажение тестового результата через общий Docker volume или ключи — полностью исключить.
